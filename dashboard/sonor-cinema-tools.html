Seven tools, one set of numbers

Every tab shares the same room.

Change the screen and the viewing angles, throw, riser and speaker angles all move with it. Save the result as an option; mark one ★ Final and Cinema Design references it.

Screen

Any ratio from any one figure; CIH / CIW conversions, masking bars, largest-that-fits, common sizes.

Viewing

H FoV per row vs SMPTE / THX / CEB23 / ITU, pixels-per-degree, vertical sightlines.

Projector

Throw ratio ↔ distance ↔ width, lens position check, foot-lamberts vs SMPTE 196M, lumens needed.

Riser

Sightline-driven riser heights per row, rounded build heights, step splits (Part K).

Room

Ratio vs Sepmeyer / Louden / Bolt, axial modes with coincidence flags, Schroeder.

Audio

RP22 recipes placed in this room, CD colour coding, azimuth / elevation checks, sub conventions.

Output

Strip + scale plan + section + schedules — print, SVG, save, ★ Final.

Linked

Adopts CD room / screen / seating; the ★ Final option publishes to projects.metadata.cinema_tools.
